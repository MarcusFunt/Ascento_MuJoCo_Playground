# Blender environment asset

The Blender motion importer uses the warehouse as actual 3D scene geometry.
Place the downloaded Sketchfab ZIP package at
`warehouse_fbx_model_free.zip`; the importer also accepts an extracted package
directory or an FBX path with `--warehouse`. Package textures are packed into
the saved `.blend` scene.

- Model: [Warehouse FBX Model Free](https://sketchfab.com/3d-models/warehouse-fbx-model-free-daa7fd3ff88945298d00045ca40a4c03)
