# Blender warehouse environment asset

The warehouse model is vendored as `warehouse_fbx_model_free.zip` and is the
default environment used by `tools/blender/import_motion.py`. The importer
packs the FBX textures into the saved `.blend` scene.

- Model: [Warehouse FBX Model Free](https://sketchfab.com/3d-models/warehouse-fbx-model-free-daa7fd3ff88945298d00045ca40a4c03)

- Required attribution and change notice: see [`WAREHOUSE_ATTRIBUTION.txt`](WAREHOUSE_ATTRIBUTION.txt).

The archive contains `source/Warehouse.fbx` and five source texture maps under
`textures/`. Keep the original archive and attribution together when moving the
asset package.
